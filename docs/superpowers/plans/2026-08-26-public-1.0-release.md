# 微信发送 1.0 公开发布实施计划

> **For Codex:** Follow the repository tests and verification commands in order; do not publish until local acceptance passes.

**Goal:** 将当前应用整理、验证并发布为 GitHub 上的公开 `1.0.0` 版本。

**Architecture:** 保持现有 SwiftUI 单进程 macOS 应用结构。发送任务继续由本地 JSON 状态、调度器和基于 Apple Events/CGEvent 的微信界面自动化协作完成；本次只增加发布级文档、版本元数据、仓库元数据和分发产物，不改变已经验收的联系人搜索行为。

**Tech Stack:** Swift 5.10、SwiftUI、Swift Package Manager、AppKit、Accessibility/AXUIElement、ApplicationServices/CGEvent、LaunchAgent、Swift Testing、zsh、Git/GitHub Releases。
