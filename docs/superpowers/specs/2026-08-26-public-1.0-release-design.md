# 微信发送 1.0 公开发布设计

## 目标

把当前可用的 macOS 本机微信发送工具整理为首个公开稳定版本，并发布到 GitHub。公开仓库使用 `main` 分支，版本号与标签统一为 `1.0.0` / `v1.0.0`。

## 发布内容

- 公开仓库：`Xiangcainoeat/wechat-send-macos`
- 应用版本：`1.0.0`，构建号 `100`
- Git 标签：`v1.0.0`
- GitHub Release：`微信发送 1.0`
- Release 附件：可直接解压运行的 macOS 应用压缩包

## 文档结构

README 首屏直接说明产品用途、工作方式和关键安全边界；随后覆盖功能、技术栈、各环节实现原理、构建安装、首次使用、限制和隐私。

## 安全边界

项目仅通过 macOS 辅助功能控制已经登录的微信，不读取或解密微信数据库，不保存微信凭据，不截图、不做 OCR，也不尝试绕过 macOS 权限。联系人由用户输入，并要求用户确认搜索名称唯一。

## 验收标准

1. Swift 测试全部通过，README 发布契约测试通过。
2. `dist` 和 `/Applications` 中的应用均显示 `1.0.0`，且签名校验通过。
3. Release 压缩包可完整解压，包含签名后的 `.app`。
4. GitHub 仓库为 Public，`main` 与 `v1.0.0` 可匿名读取。
5. GitHub Release 已公开且包含应用压缩包。
